# LaboraVR
Part of my portfolio → [jefferynketiah.com](https://jefferynketiah.com)

VR labs for schools without physical lab access — immersive chemistry, physics, and biology simulations for safe, affordable science education. Built from three years teaching Cambridge IGCSE physics and chemistry in Accra.

**[Live site](https://laboravr.vercel.app)**

Built with Next.js, React Three Fiber, Three.js, and Tailwind CSS.
